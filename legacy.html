무드 / 세계관

파이프라인 안내

HookFlow Studio는 Nano Banana / GPT 이미지 · Seedance에 붙여넣을 프롬프트를 생성·관리합니다. 실제 생성은 각 도구에서, 여기서는 프롬프트 제작·한글 나레이션 편집에 집중합니다.

②
마스터 시트 프롬프트

인물/제품 레퍼런스 시트 → Nano Banana·GPT에 붙여넣기 → 일관된 캐릭터/제품 확보

③
12컷 콘티(스토리보드) 프롬프트

한 장 콘티 시트 → 이미지 생성. 컷별 한글 대사·발음 교정 편집

④
Seedance 컷별 영상 프롬프트

화면비 포함 컷별 카메라·모션 프롬프트 → Seedance로 영상화

⑤
한국어 나레이션 스크립트

TTS/더빙용 스크립트 + 발음 교정 메모(별도 편집)

⑥
리드마그넷 PDF + 인스타 자동화

카드뉴스/PDF 생성 + 댓글→DM→PDF 자동발송 설계

② 마스터 시트 프롬프트

인물 또는 제품의 일관성 레퍼런스 시트를 만듭니다. 이 이미지를 이후 모든 컷 생성에 참조로 사용해 캐릭터가 유지됩니다.

이미지 생성 프롬프트Nano Banana / GPT Image

💡 생성된 시트 이미지를 저장 → 콘티/Seedance 단계에서 "참조 이미지"로 업로드하면 캐릭터가 일관되게 유지됩니다.

③ 콘티 · 스토리보드

① 프로젝트·② 마스터 시트를 설정한 뒤 "프로젝트 설정으로 콘티 자동 완성"을 누르면 각 컷의 썸네일·역할·자막·나레이션·발음이 자동으로 채워집니다. 이후 편집하고 "콘티 시트 프롬프트 생성"을 누르면 이미지 생성용 프롬프트가 나옵니다. (한글 대사·자막 / 발음 메모는 따로 관리)

🤖 AI 주제 생성기 URL/주제 학습

①을 누르면 그 자리에서 컷(썸네일·자막·훅·나레이션·그레이드)이 바로 채워지고 동시에 학습용 프롬프트가 복사됩니다. PDF·URL까지 반영한 더 정교한 결과를 원하면, 복사된 프롬프트를 GenSpark/Claude/Gemini에 붙여 생성한 뒤 그 결과(JSON)를 ②에 붙여넣으세요. (②는 예시가 아니라 AI가 준 실제 JSON을 넣는 칸입니다.)

④ 영상 제작 · 비용 비교

같은 콘티를 만드는 두 가지 길입니다. 저비용(스틸+캡컷)이 AI 영상생성 대비 수십 배 저렴합니다.

✅ 저비용 · 권장

스틸 이미지 + 캡컷 켄번즈

정지 이미지 -장 생성(Nano Banana) → 캡컷에서 줌/팬(켄번즈)으로 움직임 → TTS·자막. 영상생성 결제 없음.

≈ 0.5 크레딧
이미지 ~0.1cr × 장수 + 캡컷/자막 무료 + TTS 무료~소액
AI 영상생성 (힉스필드/Seedance)

클립 직접 생성

컷마다 영상 클립을 생성. 품질은 높지만 클립당 과금이 누적됩니다.

≈ 45 크레딧
10초 클립 ~45cr 기준 · 컷/재생성마다 증가
💡 추천 워크플로우 — 전 컷은 저비용 스틸+캡컷으로 만들고, 훅(1컷)이나 결정적 1컷만 필요하면 그때만 AI 영상생성 1회. 10편이면 수백 크레딧 → 몇 크레딧으로 절감됩니다.

저비용 CapCut 컷시트 생성 권장

컷별 스틸 이미지 프롬프트 + 캡컷 켄번즈 모션 + 한글 자막·타이밍 + SFX를 한 번에. 이미지만 생성하면 캡컷에서 바로 영상이 됩니다.

CapCut 저비용 컷시트

🖼 스틸 프롬프트는 Nano Banana/GPT에, 자막·모션은 캡컷에 적용하세요. 커버 카피는 캔바에서 얹기(AI로 한글 굽지 말 것).

Seedance / 힉스필드 AI 영상 프롬프트 선택 · 고비용

핵심 컷만 골라 AI로 영상화할 때 사용. 화면비()·카메라 모션·그레이드·오디오 포함.

Seedance 시퀀스 프롬프트

💡 비용 절감: 핵심 1~3컷만 영상화하고 나머지는 위 저비용 컷시트로 만드세요.

⑤ 한국어 나레이션 · 발음 스크립트

TTS/더빙용 한국어 스크립트를 컷별로 관리합니다. 발음 교정 메모는 한자어·영어·숫자를 실제로 읽는 방식으로 따로 적어두면 TTS 오독을 막습니다.

나레이션 스크립트 (한국어)TTS / 더빙용
발음 교정 팁 — 한자어/영어/숫자는 TTS가 자주 오독합니다. 컷 편집(③)의 "발음 교정 메모"에 예: 재테크→재테크, 3.5%→삼 점 오 퍼센트, ROI→아르오아이 처럼 적어두면 이 스크립트에 자동 병기됩니다.

⑥ 리드마그넷 · 카드뉴스 PDF (토지 DM 자료)

댓글 「토지」 → DM으로 보낼 주제별 PDF/카드뉴스. ③에서 프리셋을 불러오면 주제에 맞는 PDF 내용이 자동으로 채워집니다. "카드 미리보기 → PDF로 저장(인쇄)"으로 이미지/PDF 완성.

인스타 댓글 → PDF 자동발송 설계

GitHub Pages(정적)로는 발송 서버를 못 돌립니다. 아래 두 경로 중 하나로 백엔드/자동화를 붙이세요. (설계 + 가이드)

1
게시 & 트리거 설정

정적릴스/카드뉴스 게시 → 캡션에 "댓글에 가이드 남기면 DM으로 PDF 드려요" 트리거 키워드 안내

2
댓글 감지

외부ManyChat 또는 Meta Graph API 웹훅이 지정 키워드 댓글을 실시간 감지

3
자동 DM 발송

외부Instagram Messaging API로 DM 자동 전송 (댓글 답글 + DM 2단)

4
PDF 링크 전달

정적DM에 PDF 다운로드 링크(이 GitHub Pages/Drive에 올린 PDF) 첨부 → 리드 확보

경로 A · ManyChat 노코드 · 추천

  1. ManyChat 가입 → Instagram 계정 연동 (프로 플랜에서 IG 자동화 지원)
  2. Automation → Instagram Comment 트리거 생성, 키워드=가이드
  3. 액션: 댓글 답글 + Send DM → 버튼에 PDF 링크
  4. DM 본문에 "팔로우하면 다음 편도 받기" CTA로 팔로우 전환

Meta 앱 심사 불필요. 가장 빠른 출시 경로.

경로 B · 직접 웹훅 개발 · 유연

  1. Meta 개발자 앱 생성 → Instagram 그래프 API + instagram_manage_comments, instagram_manage_messages 권한
  2. Cloudflare Workers / Vercel Function에 웹훅 수신 엔드포인트 배포
  3. comments 이벤트 구독 → 키워드 매칭 시 Send Message API 호출
  4. 앱 심사(App Review) 통과 후 라이브 전환

코드 스켈레톤은 저장소의 INSTAGRAM_AUTOMATION.md 참고.

주의 — 인스타 자동 DM은 Meta 정책(24시간 메시징 윈도우, 스팸 금지)을 반드시 준수해야 계정 제재를 피합니다. 키워드 트리거는 정책상 허용되나, 무분별한 대량 DM은 금지입니다.
