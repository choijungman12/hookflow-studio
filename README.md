# HookFlow Studio 🔑

AI 영상 제작 파이프라인 — **프롬프트 스튜디오**. 단일 `index.html`, 빌드 불필요, GitHub Pages 바로 배포.

이미지 생성(Nano Banana / GPT) → 마스터 시트 → 12컷 콘티 → **Seedance** 영상 → 한국어 나레이션 → 리드마그넷 PDF까지, 각 도구에 붙여넣을 **프롬프트를 생성·관리**하고 한글 대사/발음을 따로 편집합니다.

## 💸 최소비용 제작 (핵심)
힉스필드/Seedance **영상생성(클립당 ~45크레딧)** 대신, **정지 이미지(Nano Banana ~0.1크레딧/장) + 캡컷 켄번즈 모션(무료) + TTS(무료~소액) + 자막(무료)**.
- **④ 영상제작·비용** 탭 → "**CapCut 저비용 컷시트 생성**": 컷별 스틸 프롬프트 + 켄번즈 모션 + 한글 자막/타이밍 + SFX + 커버(캔바) 지침을 한 번에.
- 비용 비교 카드가 저비용 vs AI영상 크레딧을 실시간 계산.
- 10편이면 **수백 크레딧 → 몇 크레딧**.

## 🤖 AI 주제 생성기 (③ 콘티) — 새 주제를 학습해서 콘티 생성
정적 사이트라 앱이 직접 URL을 못 읽으므로, **GenSpark/Claude/Gemini(URL 학습 가능)**를 활용하는 왕복 방식:
1. 주제/키워드 + 참고 URL + 포맷(9:16/16:9) 입력 → **"① AI 학습·생성 프롬프트 복사"**
2. 복사한 프롬프트를 GenSpark/Claude/Gemini에 붙여넣어 학습·생성 (JSON 출력)
3. 결과 JSON을 **"② 스토리보드 생성 + 내 프리셋 저장"** 에 붙여넣기 → 새 콘티 생성 + PDF 자동채움 + "⭐ 내 프리셋" 저장
- **빠른 초안**: AI 없이 앱 내에서 주제만으로 즉시 12컷 뼈대 생성(편집용).
- 어떤 주제를 넣어도 **충격→해법=토지→댓글「토지」DM**으로 귀결.

## ⚡ 내장 프리셋 (③ 콘티 → 시나리오 프리셋)
- **10초 충격→토지 릴스 10편**: 국민연금 배신 / 평생 세입자 / 검은 화요일 / 월급 30년 / 대출 문 / 도박 공화국 / 현금 녹음 / 인구감소 / 은퇴 30년 / 그린벨트. 4비트(충격 0-2s → 심화 2-5s → 해법=토지 5-8s → 결론+댓글「토지」DM 8-10s), 결론은 항상 "결국 답은 땅".
- **12컷 콘티 2편**: 「부자들은 왜 땅에서 시작했나」, 「주식·코인 시대의 착각」.
- 불러오면 주제·인물·의상·컷·나레이션·발음이 채워지고, 이후 자유 편집.

## ✨ 핵심 기능

| 단계 | 기능 |
|---|---|
| ① 프로젝트 | 주제 8종, **9:16 / 16:9 / 1:1** 포맷, 벤치마크 훅 7종(⚡10초 충격→토지 포함) |
| ② 마스터 시트 | 인물/제품 일관성 레퍼런스 시트 프롬프트 (Nano Banana·GPT용) |
| ③ 콘티 | 시나리오 프리셋 + 컷 편집기. **한글 대사·자막**과 **발음 교정 메모**를 따로 관리 |
| ④ 영상제작·비용 | **저비용 CapCut 컷시트**(권장) + 비용 비교 + Seedance/힉스필드 AI영상(선택) |
| ⑤ 나레이션 | TTS/더빙용 한국어 스크립트 + 타임코드 + 발음 병기 |
| ⑥ 리드마그넷 | 카드뉴스/PDF(인쇄 저장) + **DM 트리거 키워드** + 인스타 댓글→DM→PDF 자동화 설계 |

- **자동저장**: 브라우저 localStorage. 프로젝트 여러 개 전환 가능.
- **백업/이동**: JSON 내보내기·불러오기.
- **API 키 불필요**: 정적 사이트 100% 동작. 생성물은 GenSpark/Nano Banana/Seedance에 붙여넣어 사용.

## 🚀 GitHub Pages 배포 (5분)

1. GitHub에서 새 저장소 생성 (예: `hookflow-studio`)
2. 이 폴더의 `index.html`을 저장소 루트에 업로드(또는 push)
   ```bash
   cd hookflow-studio
   git init
   git add .
   git commit -m "HookFlow Studio"
   git branch -M main
   git remote add origin https://github.com/<사용자>/hookflow-studio.git
   git push -u origin main
   ```
3. 저장소 **Settings → Pages → Source: `main` / `/root`** 저장
4. 잠시 후 `https://<사용자>.github.io/hookflow-studio/` 접속

### 실시간 수정·보완
- `index.html` **한 파일만** 고치면 됩니다. 커밋/푸시하면 몇 분 내 반영.
- 로컬에서 확인: 파일을 브라우저로 그냥 열어도 됩니다 (더블클릭 → 크롬).
- 구조: 상단 `<style>`(디자인) → `<body>`(화면) → 하단 `<script>`(로직/프롬프트 템플릿).
  - 프롬프트 문구를 바꾸려면 `<script>`의 `genBoard()`, `genSheet()`, `genSeedance()`, `genNarration()` 함수 편집.
  - 주제/훅 템플릿을 늘리려면 상단 `TOPICS`, `HOOKS` 배열에 항목 추가.

## 🧭 실전 워크플로우

1. **① 프로젝트**에서 주제·포맷·훅 선택 → 무드/세계관/슬로건 확정
2. **② 마스터 시트** 프롬프트 복사 → Nano Banana/GPT로 인물·제품 시트 생성 → 이미지 저장
3. **③ 콘티** 12컷 편집(썸네일/ACTION/CAMERA + 한글 대사·발음) → 시트 프롬프트 복사 → 이미지 생성기에 **마스터 시트 참조**와 함께 넣어 콘티 이미지 생성
4. **④ Seedance** 컷별 프롬프트 복사 → 핵심 컷 영상화
5. **⑤ 나레이션** 스크립트 복사 → ElevenLabs/클로바더빙 등에서 한국어 음성 생성 (발음 메모대로)
6. 편집 툴에서 컷 영상 + 나레이션 + 자막 합성 → 릴스/유튜브 업로드
7. **⑥ 리드마그넷**에서 카드뉴스 PDF 만들고 캡션 복사 → 게시 → 댓글→DM 자동화(`INSTAGRAM_AUTOMATION.md`)
